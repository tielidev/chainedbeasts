## How many beasts are announced?

Eight are listed in the October 7 launch overview. That figure refers to the announced full game. It should not be replaced by the number visible in a Demo menu, a promotional screenshot or an older playtest.

The May update explicitly named Rhino and Ibex as additions to a reworked beast lineup. We cover the evidence and its limits in the [Rhino and Ibex overview](/beasts/rhino-and-ibex/). Other names, unlock costs and ability values are omitted until verified.

## How do variants work?

The developer says variants can have different stats and abilities. That means a variant is not necessarily just a costume. Before choosing one, compare its actual current description with the version you already understand.

Our advice is to change one meaningful part of your setup at a time. That makes it easier to tell whether a different movement feel, ability or item choice helped. Pair the choice with your [weapon plan](/combat/weapons-and-equipment/) rather than evaluating the character in isolation.

## How should you approach unlocks?

The May announcement describes earning XP by playing a beast and unlocking variants. The launch overview does not establish that every beast uses the same unlock condition. Check the in-game requirements for each locked option instead of assuming a universal experience threshold.

For a new player, understanding one available beast is a more actionable goal than chasing an unverified tier list. Use the [first-run guide](/guides/beginner-guide/) to establish a baseline, then compare the choices your actual game exposes. If you report an unlock correction, include the game version and a screenshot of the requirement.

## What is the difference between a beast, a variant and a cosmetic?

Use the developer's categories carefully. The launch overview counts eight unlockable beasts, while variants are described as potentially changing stats or abilities. Cosmetic options change presentation. Those are different categories of content, so adding all of them together does not produce a valid playable-character count.

| Category | Check before describing it |
| --- | --- |
| Beast | The selectable character's name and current availability |
| Variant | Whether its description changes an ability, stat or other behavior |
| Cosmetic | Whether the game presents it as appearance rather than a mechanical change |
| Unlock | The exact condition shown for that particular option |

An option that looks different may still need its description checked. Equally, a familiar-looking variant can change how an action works. Read the current screen instead of using artwork as a substitute for mechanical evidence.

## What should you test after unlocking a variant?

Change one element of your setup and repeat an action you already understand. Note whether the description changes the way you should approach distance, timing or a team interaction. This is an editorial learning method, not a claim that every variant affects those properties.

Keep screenshots of the requirement and the resulting description if you contribute a correction. They let us separate what the menu establishes from an interpretation of a combat result. A complete progression table will need that evidence for each entry; it cannot be derived from the announced total alone.
