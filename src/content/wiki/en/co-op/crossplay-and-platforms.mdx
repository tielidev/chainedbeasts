## Which platforms are announced?

Featherweight Games announced the named console versions alongside Steam, with Game Pass on Xbox and Windows PC from launch. The official Steam listing includes Windows and macOS support. Availability and subscription requirements should be checked in the store for your platform and region.

The [launch guide](/news/release-date-platforms/) covers the announced timing. A store listing or subscription inclusion is separate from the details of how two friends join one another.

## Does the game support cross-play?

Yes, the developer's launch overview explicitly advertises online cross-play. We have not verified a complete compatibility matrix or exact friend-code flow across all systems. Avoid assuming that a Steam feature label establishes every possible pairing.

Before buying specifically to play with someone, check the current in-game connection options and any official platform-specific notes. Our [multiplayer guide](/co-op/multiplayer-guide/) provides a preparation checklist without inventing menu steps.

## Is cross-save also confirmed?

The Xbox product page lists Xbox Play Anywhere. Microsoft's program FAQ describes shared progress between its supported Xbox and Windows PC editions using the same account. Our [Play Anywhere guide](/guides/xbox-play-anywhere/) explains that specific boundary; we have not performed a Chained Beasts transfer test.

This does not establish Steam, PlayStation or Nintendo save transfers. [Steam Cloud](/guides/steam-cloud-saves/) is separately listed and does not prove shared progression across every platform. Treat cross-play, cloud saves and cross-save as separate features.

Likewise, [Remote Play Together](/co-op/local-co-op/) is a Steam session-sharing feature and should not be used as a substitute for a platform compatibility statement.

## What remains to be verified?

Exact mixed local-and-online limits, platform-pairing restrictions and account requirements need current interface or developer evidence. If reporting a correction, include both platforms, game versions and the relevant official note or screenshot. That evidence is more useful than a general claim that multiplayer did or did not work.

## Which multiplayer terms should you keep separate?

Use the following distinctions when planning a purchase or a party. A platform feature label answers only the question it names; it does not automatically answer every question about accounts and progress.

| Term | The question it answers |
| --- | --- |
| Cross-play | Can players on different platforms participate together? |
| Local co-op | Can players share one system's game session? |
| Remote Play Together | Can Steam stream a host's local session and share inputs? |
| Steam Cloud | Can supported Steam saves synchronize through Steam? |
| Cross-save | Can progression move between different platform ecosystems? |

The sources establish the advertised cross-play feature, Steam Cloud label and the Xbox Play Anywhere program boundary. Transfers outside that documented boundary still need explicit support. Do not treat a successful controller connection or a shared account name as evidence that progress transfers.

## What should friends confirm before choosing platforms?

Write down the exact products each person intends to use: Steam on PC, a console version, or a Game Pass edition. Check the current store page and game connection options for that combination. Include any subscription and internet requirements listed by the relevant platform, without assuming the rules match another console.

If you cannot find a documented pairing, ask for that precise combination rather than a general “does cross-play work?” A useful answer names both platforms, the installed versions and the invitation method. This keeps a limited observation from becoming an unsupported compatibility matrix for every system.
