## Is Chained Beasts split screen or shared screen?

Yes, Chained Beasts has local couch co-op for up to four players on one system, but no official source we checked confirms that it uses split screen. The developer describes its local mode as "couch co-op", and the Steam requirement notes call it "same-screen co-op". Steam's "Shared/Split Screen Co-op" tag and Xbox's shared/split screen feature are combined store labels that do not say which view the game uses, so we treat split screen as unconfirmed. Official promotional screenshots show the chained fighters together in one shared arena.

See the [developer's launch announcement](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1846651706678663) and the [Steam listing](https://store.steampowered.com/app/3569420/Chained_Beasts/) for the exact wording.

## What do you need for couch co-op?

Check your platform's supported input devices and connect the required controllers before starting. Nintendo's listing states that multiplayer requires a compatible controller per player. On PC, Steam recommends a gamepad and lists full controller support.

Use the game's current player-join prompts to assign inputs. We have not verified a universal keyboard-sharing arrangement or a specific join button for every platform, so this guide does not promise either. See [controller preparation](/guides/controls-and-controller/) for input checks.

## Is Remote Play Together the same as cross-play?

No. Remote Play Together is listed as a Steam feature for sharing the host's local multiplayer session. It should not be used as evidence that a particular console-to-PC matchmaking combination is supported.

For platform compatibility, read the [cross-play guide](/co-op/crossplay-and-platforms/). For the broader online mode, start with our [multiplayer overview](/co-op/multiplayer-guide/).

## What should you check when a player cannot join?

Our suggested diagnostic sequence is to confirm that the controller works in menus, verify that it is assigned to the intended player, and simplify the session before changing network settings. For Remote Play, also inspect the Steam session's input-sharing controls.

Record which step fails: detecting the device, joining the local lobby or connecting the remote guest. Those are different problems and should not be grouped into a single unsupported fix.

## Which shared-session setup matches your group?

Start with where the game runs and how the players provide input. A group watching one physical screen is not using the same delivery method as a friend streaming that screen over the internet, even when both use the game's local multiplayer mode.

| Setup | Where the game runs | What to check first |
| --- | --- | --- |
| Couch co-op | One local system | Supported controllers and player assignment |
| Steam Remote Play Together | The host's computer | Steam invitation and shared-input controls |
| Native online co-op | Each player's own game session | Version, platform and the game's connection options |

Do not use this table as proof that the three methods can all be combined. Mixed local-and-online support needs a separate statement or current test. Likewise, a four-player maximum does not establish how many people can share a keyboard.

## How should you prepare the room and input devices?

Connect devices before the session, make sure each player can read the prompts, and agree on which controller belongs to whom. Test joining and movement before beginning a serious attempt. If input is ambiguous, disconnect unused devices and confirm assignment again instead of changing every setting at once.

For a remote guest, identify whether the failure is receiving the picture, joining the Steam session or controlling a character. A clear stream with no movement suggests a different question from a connection that never starts. Record the failing stage and any error message; we do not promise that a single controller or network change will fix all three.
